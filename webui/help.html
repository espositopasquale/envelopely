Purpose and disclaimer

Envelopely is intended for legitimate, relevant correspondence—not unsolicited or indiscriminate bulk messaging. It helps organize, prepare, personalize, review, and send messages in a clean and controlled way.

Automation does not remove the sender's responsibility. Contact only relevant recipients, use their information lawfully, review every message, identify yourself accurately, and respect refusals and opt-outs.

Personalization must remain truthful. Do not fabricate familiarity, personal knowledge, endorsements, urgency, or a relationship that does not exist.

Quick start

  1. Use File to upload contacts and a CV or attachment.
  2. Review the message template.
  3. Run preflight.
  4. Create and inspect previews.
  5. Send the confirmed count.

Files

The File menu offers two choices:

  • Upload contacts accepts CSV files.
  • Upload CV / attachment accepts PDF, DOC, DOCX, and TXT files.

Uploaded files remain in local project folders.

Contact CSV

Required columns:

Email,Company,Greeting,Subject,PersonalizedText,Status,Batch

Optional columns are Language and Audience. The default eligible status is Not contacted.

Messages and templates

The Messages menu opens the template editor. Templates are plain text and support fields such as Greeting, PersonalizedText, SenderName, SenderTitle, SenderEmail, and SenderWebsite.

Save a new name when testing a variation.

Settings

The Settings menu opens a dedicated page for sender and SMTP configuration. You can set host, port, TLS mode, username, app password or token, sender address, sender name, and reply-to address.

The password field remains empty when settings are loaded. Leave it empty to preserve the current password.

Configuration uses .env first and .env.local as fallback.

Review workflow

StepResult
PreflightChecks contacts, templates, duplicates, status, and attachments.
PreviewCreates local EML files for inspection.
SendRuns preflight again and confirms the exact count.

Command line

Guided mode:

./envelopely --interactive

Preflight example:

./envelopely --contacts contacts.csv --template templates/default.txt --attachment document.pdf --check

On Windows, use .\envelopely.exe.

Troubleshooting

Greeting does not update

Set MAIL_FROM_NAME, restart the Web UI, and refresh the browser.

SMTP is not configured

Open Settings and provide at least the SMTP host and sender address.

Port 8080 is busy

Stop the older server or set ENVELOPELY_WEB_ADDR to another local address.

A contact is skipped

Review status, email validity, duplicate history, generic-inbox setting, and run limit.
